# FOMAT Website — Project Context for Claude

## О проекте
Презентационный сайт-каталог для компании **FOMAT** — поставщик премиальных fit-out материалов (Ташкент, Узбекистан).

**Клиент:** FOMAT (Ташкент)
**Разработчик:** вайбкодер (заказчик этого чата)
**Репозиторий:** https://github.com/diyoreg/fomat-website
**Стек:** Next.js 16, TypeScript, Tailwind CSS v4

## Что сделано

- **Дизайн:** минималистичный, премиальный, адаптивный (mobile-first)
- **Анимации:** scroll-triggered через `useInView` hook (IntersectionObserver)
- **Табы:** страницы с несколькими брендами (Shaw/FOMAT, JEB/FOMAT) переключаются табами
- **Контент:** весь текст из ТЗ (`extracted_content.txt`) уже внесён на страницы
- **Плейсхолдеры:** вместо фото — цветные блоки с фирменными цветами (клиент предоставит фото)
- **Форма:** страница контактов с формой (нет бэкенда — показывает success state)


## Технические детали

- Все страницы с анимациями — `"use client"` компоненты
- Страница `/catalog/walls` — server component (нет хуков)
- Tailwind v4 используется через `@import "tailwindcss"` в `globals.css`
- Кастомные CSS-переменные брендовых цветов определены в `@theme inline {}`
- Next.js Image используется для логотипа (`priority` на хедере)
