# Инструкция по работе с FOMAT CMS

Эта инструкция объясняет как загружать фотографии и контент на сайт fomat.uz через панель управления (Sanity Studio).

## Вход в Studio

1. Открой ссылку: **`https://<домен-сайта>/studio`** (на проде) или `http://localhost:3000/studio` (для разработчика).
2. Войди через Google-аккаунт, на который тебя пригласили.
3. Появится список разделов слева — это и есть «папки» для контента.

> Если страница пишет «Connect this studio to your project» — нажми **Add development host** (для localhost) или **Register this studio** (для прод-домена). Это разовая настройка CORS.

---

## Общие правила

| Действие | Как |
|---|---|
| Создать документ | `+` справа от названия раздела |
| Удалить | Открыть документ → три точки сверху → **Delete** |
| Сохранить черновик | Происходит автоматически (черный кружок = draft) |
| **Опубликовать на сайт** | Кнопка **Publish** внизу справа (Ctrl+Alt+P / Cmd+Opt+P) |
| Снять с публикации | Три точки → **Unpublish** |
| Кадрировать фото | Клик на превью загруженного фото → перетащи фокус (hotspot) и рамку crop |

**Важно:** только опубликованные документы (зелёный значок) показываются на сайте. Чёрные точки — это черновик, его никто кроме редактора не видит.

**Изменения на сайте появляются через ~60 секунд** после публикации (кэш). Иногда быстрее. Если не видишь правок — подожди минуту и обнови страницу.

## 1. Слайдер на главной

**Где появится:** главная страница `/`, справа от заголовка hero.

**Сколько документов:** 1 (один на весь сайт).

**Что заполнять:**
- **Изображения слайдера** → нажми `Add item` → загрузи 3–10 фото офисных проектов / интерьеров. На каждом можно ввести **Alt-текст** (необязательно, помогает SEO).

Слайдер автоматически листается раз в 4–5 секунд по кругу.

---

## 2. Коллекция ковровой плитки

**Где появится:** страницы `/catalog/floors/carpet-tiles` (отдельно для брендов Shaw и FOMAT).

**Сколько документов:** по одному на каждую коллекцию (Foundry, Outline, Equilibrium, …). От клиента приходят папки — название папки = название коллекции, фото внутри = Изображения коллекции.

**Что заполнять для каждой коллекции:**
- **Название коллекции** — например, `Foundry`
- **Бренд** — Shaw Contract или FOMAT
- **Порядок отображения** — число (`0`, `1`, `2`…). Меньше = выше в списке.
- **Изображения коллекции** — несколько фото, листаются слайдером внутри карточки.

Публикуй каждую коллекцию отдельно.

---

## 3. Перегородки — изображение раздела

**Где появится:** страница `/catalog/partitions`, в секции «Линейка JEB» / «Линейка FOMAT».

**Сколько документов:** **5 штук** — по одному на каждую пару бренд + раздел:

| № | Бренд | Раздел |
|---|---|---|
| 1 | JEB | Перегородки |
| 2 | JEB | Двери |
| 3 | FOMAT | Перегородки |
| 4 | FOMAT | Двери |
| 5 | FOMAT | PODS *(только для FOMAT)* |

**Что заполнять:**
- **Бренд** — выбери из списка
- **Раздел** — выбери из списка
- **Изображение** — одно общее фото для этого раздела (например, обзорное фото перегородок JEB)

JEB не имеет PODS — поэтому для JEB достаточно 2 документов.

---

## 4. Галерея раздела

**Где появится:**
- `/catalog/acoustics` — раздел `Акустика`
- `/catalog/floors/raised-floors` — раздел `Фальшполы`

**Сколько документов:** **2 штуки** (один на акустику, один на фальшполы).

**Что заполнять:**
- **Раздел** — выбери Акустика или Фальшполы
- **Изображения** — массив всех фото для этого раздела (на сайте они идут грид-сеткой с эффектом увеличения при наведении)

Первое фото становится главным на overview-блоке, остальные показываются в секции «Галерея».

---

## 5. Реализованный проект

**Где появится:** страница `/projects` (раздел «Наши клиенты»), как карточки с фото и описанием.

**Сколько документов:** по одному на каждый проект.

**Что заполнять:**
- **Название проекта** — например, `Бизнес-центр «Центр»`
- **Год** — например, `2024`
- **Описание** — короткий абзац о проекте
- **Решения** — теги материалов, которые использовали: `Carpet Tiles`, `LVT`, `Перегородки JEB`, `Акустика` и т.п. Вводишь через Enter, каждое — отдельный тег.
- **Главное фото** — обложка карточки
- **Порядок отображения** — число (меньше = выше).

Пока документов нет — на сайте показываются 6 дефолтных плейсхолдер-карточек. Как только появится хотя бы один реальный проект — плейсхолдеры исчезнут, покажутся только опубликованные проекты.

---

## 6. Логотип клиента

**Где появится:** страница `/projects`, блок «С нами работают» внизу — grid с логотипами компаний-клиентов.

**Сколько документов:** по одному на каждого клиента.

**Что заполнять:**
- **Название клиента** — текст для подсказки при наведении
- **Логотип** — лучше прозрачный PNG или SVG (без белого фона). Размеры — любые, на сайте автоматически впишется в квадрат.
- **Порядок отображения** — число.

На сайте логотипы по умолчанию показываются в чёрно-белом, при наведении становятся цветными.

---

## 7. Картинка категории

**Где появится:** карточки на главной (`/`, секция «Наши решения») и на странице каталога (`/catalog`) — фото станет фоном карточки с тёмным градиентом сверху для читаемости текста.

**Сколько документов:** **4 штуки** — по одному на каждую категорию каталога:

| № | Категория |
|---|---|
| 1 | Напольные покрытия |
| 2 | Акустические решения |
| 3 | Перегородки и двери |
| 4 | Освещение |

**Что заполнять:**
- **Категория** — выбери из списка
- **Изображение** — общее презентационное фото для этой категории. Лучше выбирать фото с **тёмными или средними тонами** — на ярких фото может плохо читаться белый текст.

Если документ для какой-то категории не создан — карточка покажет старый сплошной цветной фон (это нормальный fallback).

---

## 8. Картинка подкатегории напольных покрытий

**Где появится:** страница `/catalog/floors` — слева на каждой из 3 карточек подкатегорий.

**Сколько документов:** **3 штуки** — по одному на каждую подкатегорию:

| № | Подкатегория |
|---|---|
| 1 | Фальшполы |
| 2 | Ковровая плитка (Carpet Tiles) |
| 3 | LVT — Люкс-Винил |

**Что заполнять:**
- **Подкатегория** — выбери из списка
- **Изображение** — одно фото на подкатегорию (без слайдера, только одна картинка).

Если документ не создан — на карточке будет цветной плейсхолдер (fallback).

---

## Что делать, если что-то не появилось на сайте

1. Проверь что документ **опубликован** (зелёный кружок, не чёрный).
2. Подожди 1 минуту и обнови страницу сайта.
3. Если всё равно нет — попроси разработчика проверить env-переменные на проде.
